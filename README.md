# Minimum Distance Edit (Levenshtein Distance) Algorithm
This is my implementation of the Levenshtein Distance Algorithm in Java, part of Group 5's Final Project in Design and Analysis of Algorithms.

## What is the Minimum Distance Edit (Levenshtein Distance) Algorithm?
It's an algorithm that calculates the minimum number of edits (replace, insert, and remove). It's commonly used in fuzzy search, autocorrect, plagiarism detection, and DNA sequence comparison.
